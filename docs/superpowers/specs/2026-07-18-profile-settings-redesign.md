# 个人设置页暗色简约改版设计

## 目标

将个人设置页融入现有设置模块，统一页面宽度、二级导航、信息层级和暗色视觉语言，同时保留资料加载、头像上传和资料保存功能。

## 范围

修改以下前端页面：

- `desktop/frontend/src/pages/ProfileSetupPage.vue`
- `desktop/frontend/src/pages/SettingsPage.vue`

不新增后端接口，不修改资料数据结构，不修改全局侧边栏，不新增主题切换。

## 导航

个人设置页显示与设置页相同的“通用 / 用量 / 账户”二级导航，其中“账户”为当前项。

- 通用跳转 `/settings`。
- 用量跳转 `/settings?section=usage`。
- 账户保持在 `/profile/setup`。

设置页读取 `section` 查询参数。未提供参数时打开 `general`；只接受 `general`、`usage` 和 `account`。提供其他值时必须显式显示错误，不回退到默认分组。查询参数变化时同步当前分组。

## 页面结构

个人设置页沿用设置页的最大宽度、页头间距和桌面两列布局。左侧为 168px 二级导航，右侧为资料内容。

右侧内容不使用外层卡片。头像区、基本信息和个人简介通过分隔线与留白组织：

1. 头像区显示头像、当前昵称和更换头像操作。
2. 基本信息包含昵称、性别和生日。
3. 个人简介使用全宽文本域。

“保存更改”位于页头，并通过 `form` 属性提交右侧表单，保证按钮与表单提交使用同一 `saveProfile` 控制流。

窄屏下二级导航变为横向标签，表单字段变为单列，页头操作保持可触达且不与标题重叠。

## 状态与错误

资料加载开始时进入显式加载状态，成功后填充表单并同步认证 store。加载失败时显示原始错误信息。

头像选择后依次执行文件读取和上传。文件为空时不执行上传；文件读取或上传失败时显示原始错误。上传期间禁用文件选择和保存操作，成功后立即更新头像预览。

保存时提交现有字段：`username`、`avatar_url`、`birthday`、`bio` 和 `gender`。成功后同步认证 store 并显示“资料已保存”；失败时显示原始错误；完成后恢复操作状态。

不添加 fallback、默认成功态、异常吞并或静默降级。

## 视觉与可访问性

- 使用现有暗色主题变量与蓝色强调色。
- 不使用渐变、装饰光斑或嵌套卡片。
- 圆角不超过 8px。
- 二级导航使用链接并通过 `aria-current` 标记当前项。
- 状态消息使用 `role="status"`，错误使用 `role="alert"`。
- 文件输入保留可访问名称；焦点状态清晰可见。
- 控件具有稳定高度，文字允许换行，桌面和窄屏均不得发生遮挡或横向溢出。

## 验证

- 新增前端源码契约测试，并先观察失败再实现。
- 设置页能通过 `?section=usage` 打开用量分组，无效参数显式报错。
- 个人设置页导航、表单提交、头像上传和错误状态均保留。
- 前端布局契约测试通过。
- Vite 生产构建通过。
- 有真实登录态时检查桌面与窄屏布局；没有登录态时明确记录限制，不绕过认证。
