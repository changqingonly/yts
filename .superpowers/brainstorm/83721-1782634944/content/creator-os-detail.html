三个核心 Tab 的内容重点

音乐

默认页。播放器、播放列表、本地导入、远程/本地音频缓存、最近生成歌曲入口。没有云登录时，桌面端可允许本地音乐离线播放。

创作 Tab

现有 Pro 歌词创作流。默认展示“创作输入 + 当前结果 + 关键节点状态”；流程图和 LLM trace 放进高级抽屉，不再抢第一屏。

资产

歌曲灵感完整落地：线索、歌名、style prompt、lyric。图片大全、音频特效先作为待建设分区，同时显示日限与空态。

用户 / 鉴权 / 积分

照搬 yuetools：RSA-OAEP-256 传输密码、Argon2id 存储哈希、access token、个人资料、积分余额与流水、生成 reserve/capture/release。

1

推荐 MVP：纵切闭环

第一期实现主壳、账号、个人设置、积分/额度、歌曲灵感资产、音乐播放器空壳与创作页迁移；图片/音效只建入口和额度展示。

2

全量照搬 yuetools

一次性迁移 Auth、Credits、Song、Music、Settings 的大部分能力。完整但风险大，容易和 YTS 现有 Python core/server 边界冲突。

3

前端壳优先

先做页面和静态状态，后端稍后接入。速度快，但账号、风控、积分无法真实闭环，和你提到的密码/积分要求不匹配。
